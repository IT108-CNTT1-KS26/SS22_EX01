## 2. Giải thích sử dụng toán tử filetype:
Việc sử dụng `filetype:pdf` giúp tiết kiệm thời gian hơn rất nhiều so với cách gõ "tải sách..." thông thường vì những lý do sau:
* Lọc trực tiếp định dạng tài liệu: Google sẽ chỉ trả về các kết quả là link dẫn thẳng đến file PDF. 
* Tránh web "rác" và quảng cáo: Giúp bạn né được các trang web yêu cầu đăng ký tài khoản, nạp thẻ VIP để tải.
* Tối ưu thao tác: Chỉ cần click vào kết quả tìm kiếm là trình duyệt sẽ mở thẳng file PDF.
